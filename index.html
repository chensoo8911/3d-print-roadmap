懶人快速上手

只有 3 步，不用懂機台細節，先讓你當天就看到實體。

三步驟

  • 機台 15 分鐘：開機校正一次、匯入 STL → BambuStudio 用預設參數切片 → 按列印
  • 捏形狀：Mac 用 ZBrushCoreMini（免費），有 iPad 的話也可以用 Nomad Sculpt付費——手指直接捏更直覺，兩選一即可（見「有機造型路線」分頁）
  • 修復並匯出：app 內建 Remesh 一鍵修復 → 匯出 STL → 丟回 BambuStudio 印
捏形狀→Remesh 修復→匯出 STL→BambuStudio 切片→A1 列印
先只用 PLA、BambuStudio 全部用預設參數——材料特性與機型差異不用現在研究，需要時再翻「材料與機型參考」分頁。

有機造型路線

目前的主線——公仔、擺飾、曲線裝飾品這類不講究精確尺寸的作品，用數位黏土邏輯直接捏。

ZBrushCoreMini（Mac，免費）/ Nomad Sculpt（iPad，付費）→ Blender Sculpt Mode（備用） Mac 用 ZBrushCoreMini，有 iPad 想要更直覺的手指操作就用 Nomad Sculpt，兩者擇一；覺得功能不夠精細再轉 Blender

ZBrushCoreMini（Mac 首選）

  • 免費、Mac 原生支援，Pixologic 官方專門給 3D 列印愛好者做的簡化版
  • 純滑鼠/繪圖板操作，捏、拉、刷都直覺，跟捏黏土邏輯一樣
  • 內建 Remesh／修復功能，匯出的模型是列印友善的密閉實體

Nomad Sculpt付費（iPad 專用）

  • 一次性購買約 NT$300，iOS／iPadOS 限定，Mac 上無法安裝
  • 手指／Apple Pencil 直接雕塑，比滑鼠操作更貼近真的捏黏土的手感
  • 同樣內建 Remesh 修復＋直接匯出 STL，社群大量公仔/擺飾都用這個做
  • 如果你之後有 iPad，這是比 ZBrushCoreMini 更直覺的選項；沒有 iPad 就用 ZBrushCoreMini 一樣夠用

Blender Sculpt Mode（備用）

  • 免費、功能更強，但介面複雜——只用 Sculpt Mode，忽略動畫/算圖等用不到的功能
  • 搭配內建 3D-Print Toolbox 外掛檢查與修復破面
  • 學習曲線比 ZBrushCoreMini 陡，但教學資源最多，卡關比較好找答案
資源 ZBrushCoreMini 官方下載 Nomad Sculpt App Store付費 Blender 官方下載

精確機能路線

備用路線——當你需要「量身訂做、要跟別的東西組裝」的機能性物件時再回來用，不是現在的優先。

方案 1 · 手動入門
Shapr3D

Mac 桌面版可用，CAD 核心跟 Fusion 360 同等級，畫出來的模型必為密閉實體，適合直接列印。

方案 2 · 跟 Claude 一起做
OpenSCAD

模型是純文字程式碼，你描述需求，Claude 直接生成/修改參數，貼上按 Render 就匯出 STL。

列印品質提醒（機能件適用）

  • 最小壁厚建議 ≥1.2mm（0.4mm 噴頭約 3 圈牆），太薄容易破洞或軟趴趴
  • 要組裝的零件之間留 0.2–0.3mm 公差，太剛好會卡死印不進去
  • 畫之前先想這個角度躺著印需不需要大量支撐
  • 匯出前確認模型是「實體」而非破面網格，避免切片跳錯誤警告
資源 Shapr3D 官方教學 OpenSCAD 官網／下載 OpenSCAD 語法速查表

軟體分工

BambuStudio 是切片軟體，不是建模軟體——建模跟切片是兩個不同的階段，各自的工具不能互相取代。

建模軟體（畫形狀）

  • 從無到有畫出一個形狀
  • ZBrushCoreMini／Blender：雕塑有機曲線
  • Shapr3D／OpenSCAD：精確尺寸的機能件

BambuStudio（切片＋控制機器）

  • 匯入模型：STL/3MF/STEP
  • 簡單擺放/縮放/旋轉/鏡射/複製排版
  • 基礎布林運算、壓文字/浮雕
  • 支撐設定、切片參數（層高/填充率/溫度）
  • 連線機器、監控列印、AMS 換料、校準精靈
簡單記：形狀在建模軟體裡生出來，BambuStudio 只負責「印之前最後調整＋切片＋控制機器」。

材料與機型參考

背景知識，非必修——不感興趣可以完全跳過，維持用 PLA／預設參數就好。

材料特性難度A1 印得動嗎
PLA最好印、環保、無異味，但怕熱（約 60°C 就軟化變形）、較脆新手首選沒問題
PETG耐候防水、較有韌性，黏床力強、容易牽絲中等印得很順
TPU軟性材料，可彎曲，適合手機殼、氣密墊圈中高（需放慢速度）可以，需調參數
ABS耐熱耐衝擊，但收縮翹曲嚴重、有異味高不建議——A1 無恆溫艙，冷風吹易翹邊
PA／PC高強度進階材料，需要高溫噴頭進階不建議——噴頭不耐磨、無恆溫艙
新手結論：PLA 練手感，PETG 做需要耐用的實品，這兩種就夠你用很久了。
機型機身能印的材料上限
A1 / A1 mini開放式機身PLA／PETG／TPU
P1P基本外殼，非恆溫艙PETG 穩定，ABS 有限
P1S全罩＋主動加熱艙ABS／ASA 印得穩
X1 Carbon全罩＋活性碳過濾＋高精度PA／PC 等高階材料
簡單記法：機身有沒有艙門包起來、有沒有主動加熱艙＝能不能印怕翹曲的高階材料。A1 沒有，乖乖用 PLA/PETG 就好。

免費模型平台

別人已經建好、可以直接下載拿去印的成品模型庫——想印什麼直接先來這裡找，不用自己從零建模。

平台特色
MakerWorldBambu 官方平台，模型自帶推薦列印參數，跟 A1 相容度最高，新手最友善
PrintablesPrusa 社群，量大質精，常有教學向模型跟設計師作品
Thingiverse歷史最久、數量最多的免費模型庫，品質參差需自己篩選
Cults3D設計感較強的作品多，免費／付費模型並存，適合找有質感的裝飾類造型
Thangs支援「以模型找模型」的視覺搜尋，找相似造型或替代零件方便
先只用 MakerWorld＋Printables 就夠——資源太多反而分散注意力，其他平台等這兩個找不到你要的東西時再展開。
